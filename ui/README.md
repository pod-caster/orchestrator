# 🎙️ Podcaster Agentic AI – Streamlit Prototype UI

This is a **Streamlit-based frontend prototype** for the Podcaster Agentic AI platform. It allows quick iteration and testing of the AI-driven podcast generation interface with basic login, topic input, and dashboard views.

---

## 🚀 Features

- 🔐 Simple login screen with email/password
- 🌐 Placeholder buttons for Google, GitHub, and Facebook login
- 🏠 Interactive dashboard after login
- ✍️ Topic input interface to simulate content generation
